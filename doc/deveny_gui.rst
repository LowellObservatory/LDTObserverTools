================
DeVeny Tools GUI
================

Run ``deveny_gui`` to open the PyQt6 application. Its tabs provide the
:ref:`grating angle calculator <deveny_grangle>`,
:ref:`collimator focus sequence estimator <deveny_collfocus>`, and
:ref:`focus analysis <dfocus>`. The :ref:`DeVeny ETC <deveny_etc>` tab is
reserved for a future exposure model.

The existing ``deveny_grangle`` and ``deveny_collfocus`` commands open their
respective tabs in this shared window. ``dfocus`` remains available as a
command-line tool.
